# Split Pixels：STM32 双人合作塔防游戏

[English README](README.md)

Split Pixels 是利兹大学本科二年级的嵌入式系统小组项目。本个人展示副本重点介绍由我独立开发的 **Game 1**：结合《植物大战僵尸》塔防玩法与《绝地潜兵 2》（Helldivers 2）方向序列输入机制的双人合作游戏。

玩家 1 负责布置防线，玩家 2 根据屏幕箭头提示，按顺序输入方向，为防御单位充能。两名玩家的职责不同且相互依赖，在微控制器上共同完成塔防挑战。

## 我的贡献

我实现了 Game 1 的游戏逻辑，包括 3 行 × 5 列战场、植物选择与放置、方向序列充能状态机、敌人波次、战斗、计分、胜负判定、操作说明、暂停选项和画面渲染逻辑。

Game 1 中使用的全部角色图像均由我手绘，并使用 Python 脚本转换成课程显示接口要求的像素数据格式。转换脚本未包含在当前仓库中。

**Game 2 和 Game 3 由其他组员开发。** 公共菜单、输入处理、音乐及硬件驱动包含课程提供或团队共同开发的组件。完整工程予以保留，以明确归属并满足构建依赖。

## 玩法与操作

敌人从战场右侧进入并向左推进。防御单位提供射击、阻挡及范围伤害等功能，部分单位的使用需要满足充能和计分条件。

| 玩家 | 职责 | 操作 |
|---|---|---|
| 玩家 1 | 选择、放置和移除防御单位 | 第一摇杆移动光标；BTN3 选择；BTN2 放置或移除 |
| 玩家 2 | 为防御单位充能 | BTN9 启动可用充能任务；第二摇杆依次输入屏幕提示的方向 |

敌人波次随游戏计时增强。当前实现包含计时达到 180 秒阈值的胜利条件；这不代表扣除暂停时间后的 180 秒有效游玩时长。

## 实现结构

| 位置 | 主要内容 |
|---|---|
| [`game_1/Game_1.c`](game_1/Game_1.c) | `Game1_Run`、游戏状态、说明页面和更新/渲染循环 |
| [`game_1/engine/engine.c`](game_1/engine/engine.c) | 战场、放置操作和方向序列充能 |
| [`game_1/engine/interact.c`](game_1/engine/interact.c) | 敌人波次、移动、战斗及胜负判定 |
| [`game_1/data/`](game_1/data/) | 植物与敌人参数 |
| [`game_1/sprites/`](game_1/sprites/) | 嵌入式像素资源，包括箭头提示 |

游戏使用 C 编写，以有限状态机、固定容量数组和 `HAL_GetTick()` 管理逻辑与计时，并接入公共 LCD、输入和声音接口。

## 硬件与构建

- STM32 Nucleo-L476RG、ST7789V2 驱动的 240 × 240 LCD、两个模拟摇杆、按键和蜂鸣器。
- C11、STM32 HAL/CMSIS、CMake 3.22 或更新版本、Ninja，以及包含 `arm-none-eabi-gcc` 的 Arm GNU Toolchain。
- 硬件配置见 [`Core/Inc/main.h`](Core/Inc/main.h) 和 [`Unit_4_1_Menu_Template.ioc`](Unit_4_1_Menu_Template.ioc)。

在仓库根目录执行：

```sh
cmake --preset Debug
cmake --build --preset Debug
```

固件输出配置在 `build/Debug/`。使用兼容 STM32 的烧录工具或调试器加载到匹配的开发板，再从菜单选择 Game 1。使用当前构建配置时，需要保留三个游戏与共享组件。

这是依赖具体硬件的课程项目源码快照。本次 README 更新未重新执行上述构建命令，也未新增硬件验证。暂停计时和重新进入游戏时的状态重置仍可进一步完善。

## 美术、音乐与项目来源

角色图像由我绘制，设计受到上述游戏启发。音乐由团队参考网上获取的乐谱素材，手工转录音符和时值，进行降调、移调及蜂鸣器播放适配。参考曲目包括《星球大战》相关钢琴谱、《绝地潜兵 2》的 **“A Cup of Liber-Tea”** 和《战地 1》主题曲。这属于音乐改编与嵌入式实现，不能将已有旋律声明为原创作曲；源乐谱的再使用许可尚未核实。
